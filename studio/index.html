Automate video publishing

Keep a list of prompts or a template, loop over it, and every call pays for itself in USDC. No keys to rotate, no monthly plan.

01Request

POST /generate/seedance-fast/5s-720p with your prompt and ratio.

02402 quote

The API answers HTTP 402 with the exact USDC amount. Rejected prompts are never charged.

03Pay and get the video

Your x402 client pays and retries, then you poll /jobs/:id for free until video_url is ready.

batch.mjs · JavaScript
// npm i @x402/fetch @x402/evm viem   (setup as in the API tab)
const prompts = [
  "a corgi surfing a small wave at sunset, cinematic",
  "a paper boat on a rainy neon street at night",
  "slow drone shot over a misty pine forest at dawn",
];

const API = "https://api.x402video.com";

for (const prompt of prompts) {
  const res = await fetchPay(`${API}/generate/seedance-fast/5s-720p`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ prompt, ratio: "9:16" }),
  });
  const { job_id } = await res.json();   // paid $1.05 USDC

  let job;
  do {
    await new Promise((r) => setTimeout(r, 5000));
    job = await (await fetch(`${API}/jobs/${job_id}`)).json();
  } while (!["succeeded", "failed", "cancelled"].includes(job.status));

  if (job.status === "succeeded") publish(job.video_url);  // your own uploader
}
