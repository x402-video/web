FAQ

Is this MiniMax Hailuo 2.3?
Live SKUs are MiniMax H3 (model id MiniMax-H3). Older Hailuo 2.x packages are not listed yet.

Why 768P not 720p?
MiniMax bills H3 in 768P / 2K tiers. We sell those tiers as-is so quotes match upstream cost.

Do I need a MiniMax API key?
No. You pay USDC on Base through HTTP 402; we hold the upstream key.
